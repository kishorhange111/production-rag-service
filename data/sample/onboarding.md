# Engineering onboarding

## Accounts
New engineers get a laptop on day one. Request repository access through the #access channel; approvals usually take one business day.

## Development environment
We use Python 3.11 and uv for dependency management. Run `make dev` to create the virtual environment and install pre-commit hooks.

## On-call
Every engineer joins the on-call rotation after their first 90 days. Shifts last one week, Monday 10:00 to Monday 10:00 UTC.
